Enabled trackers are executed when Start is pressed. Trackers without a username and password are listed as Unset until both are saved. Changes are saved automatically. Passwords are encrypted, and never sent back to the browser: a saved password is shown as dots, and deleting them removes it. An imported CSV file needs the header row trackerName,username,password, and rows starting with # are ignored. Click a tracker to select it, Ctrl+click to add or remove one, or Shift+click to select a range, to enable, disable or remove them together. The screenshots of each tracker's latest run are kept (also after a restart) and shown by expanding its row with the image button: its profile screenshots if it succeeded, or its failure screenshot if it failed. A tracker that is no longer supported is listed as Legacy, and kept with its screenshots until you remove it.

Settings cannot be changed while an execution is in progress.
